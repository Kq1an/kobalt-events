How publishing works

  1. Make a challenge (with its reward) or a news post, and click Add to my changes. Add as many as you like.
  2. Click Publish at the bottom. GitHub opens with your update already filled in - log in (password + 2FA) if it asks, and click Commit changes.
  3. The robot in your repo checks it (same rules as the mod), adds it to the feed, signs it with the key in the repo's secret vault, and puts it on the site. That takes about a minute: see it here under Live feed.
  4. Everyone's Kobalt picks it up within about 3 hours.

To change something that's live: Live feed - Edit - change it - Add to my changes - Publish (it replaces the old one). Removing a look is fine: players who won it keep it.

If something gets rejected, the robot puts it in updates/rejected with a note saying why.
